# @trademe/tractor-to-playwright

This library contains helpers which assist in the migration from [Pro/tractor](https://github.com/TradeMe/tractor) tests to [Playwright](https://playwright.dev/) tests. 

# 🔥🔥🔥 !!! It should be deleted whenever possible !!! 🔥🔥🔥

There are likely more idiomatic Playwright ways to do the things that this library enables, and tests should be migrated to use those strategies. Anything else should be considered a feature request for the Playwright team!
